# Project Title:
Movie Finder App

# Description
The Movie Finder App is a web application that allows users to easily search for movies and view detailed information about them. Users can look up movies by title and receive results that include details such as release year, overview, ratings, and other relevant information. The app is designed to make discovering and exploring movies quick, simple, and user-friendly.

This project uses HTML, CSS, JS, Node.js, Express, Supabase, and APIs to fetch and display real-time movie data. The focus is on providing a clean interface and fast search experience.

# Target Browsers
This application is optimized for modern web browsers and mobile devices, including:

iOS
Android 
Google Chrome 
Mozilla Firefox 
Microsoft Edge

The app is fully responsive and works well on both mobile and desktop devices
